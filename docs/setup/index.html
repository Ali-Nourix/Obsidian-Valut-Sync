این صفحه فقط راهنماست. Supabase را باز می‌کند، دسترسی‌های لازم را توضیح می‌دهد و به پلاگین برمی‌گرداند. نصب را خود پلاگین انجام می‌دهد.

توکن را در این صفحه وارد نکن.
اینجا هیچ فرم دریافت توکن، اسکریپت، analytics یا درخواست API وجود ندارد. توکن فقط در پنجرهٔ نصب Vault Sync، روی دستگاه خودت وارد می‌شود.
۰۱ / پروژه

یک پروژهٔ اختصاصی بساز

با حساب خودت وارد Supabase شو. یک پروژهٔ خالی برای Vault Sync بساز و تا آماده‌شدن آن صبر کن. پروژهٔ سایت یا برنامهٔ اصلی‌ات را انتخاب نکن.

شناسهٔ ۲۰ کاراکتری پروژه را از تنظیمات یا URL پروژه بردار. هزینه و سهمیه تابع پلن خودت است؛ رایگان‌بودن تضمین نمی‌شود.

۰۲ / توکن موقت

توکن محدود به همین پروژه

در Access Tokens، توکن جدید بساز. نوع Scoped را انتخاب کن، نه Legacy. فقط پروژهٔ مرحلهٔ قبل و دسترسی‌های جدول پایین را بده.

نام پیشنهادی: Vault Sync setup. کوتاه‌ترین زمان انقضای مناسب نصب را انتخاب کن. توکن‌های Scoped با sbp_fc شروع می‌شوند.

اگر از حساب sync موجود استفاده می‌کنی، API Key Secrets برای این مسیر لازم نیست؛ پلاگین کلیدهای مخفی را درخواست نمی‌کند. توکن فقط دسترسی حساب تو را محدود می‌کند و مجوزی فراتر از نقش حسابت نمی‌سازد.

فهرست همهٔ پروژه‌ها، سازمان‌ها، پرداخت، ساخت پروژه و تغییر Auth Config لازم نیست. schema با SQL، باکت خصوصی و Realtime موردنیاز را هم تنظیم می‌کند. انتخاب پروژه و دسترسی‌ها در داشبورد توسط خودت انجام می‌شود؛ این دکمه‌ها چیزی را خودکار انتخاب نمی‌کنند.

دسترسی کم، به‌معنای بی‌خطر بودن نیست. Database: Read-write اجازهٔ تغییر داده‌های پروژه را می‌دهد. API Key Secrets: Read هم کلیدهای مدیریتی را در دسترس قرار می‌دهد. فقط روی پروژهٔ اختصاصی و دستگاه و پلاگین مورد اعتماد انجام بده.

۰۳ / پلاگین

نصب را در Obsidian انجام بده

  1. Vault Sync → «نصب مستقیم با توکن محدود خودتان».
  2. شناسهٔ پروژه و توکن Scoped را وارد کن.
  3. نام پروژه را بررسی و شناسه‌اش را برای تأیید دوباره بنویس.
  4. ایمیل و رمز جداگانهٔ حساب sync را بده؛ نه رمز اصلی داشبورد.
  5. «راه‌اندازی Vault Sync» را بزن. سپس والت را انتخاب یا ایجاد کن.

جدول‌ها، RLS، باکت خصوصی، Realtime و حساب sync آماده می‌شوند. رمز حساب موجود و ثبت‌نام کل پروژه تغییر نمی‌کنند. لغو نصب، تغییرات انجام‌شده را بازگردانی نمی‌کند.

۰۴ / پاک‌سازی

توکن نصب را لغو کن

بعد از نصب، توکن را در Supabase Revoke کن. پلاگین آن را ذخیره نمی‌کند؛ حذف از حافظه با لغو در Supabase فرق دارد.

دستگاه بعدی فقط URL پروژه، کلید عمومی، همان حساب sync و همان والت را می‌خواهد. توکن نصب را برای sync نگه ندار.
